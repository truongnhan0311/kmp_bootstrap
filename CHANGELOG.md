# Changelog

Phiên bản theo `0.x`: API còn có thể đổi, mỗi thay đổi phá API được ghi ở đây.

## 0.1.0
- `appkit-mqtt` (mới): `MqttClient` MQTT 3.1.1 qua WebSocket (`WebSocketConnector`, `mqttHttpClient()`) — Last Will, QoS 0/1 (chờ PUBACK, tự PUBACK tin nhận), PINGREQ theo keepAlive, nối lại chờ ngẫu nhiên `[0, min(max, 2^n)]` giây, tự đăng ký lại chủ đề, hỏi lại `credentials`/`url` ở mỗi lần nối; `MqttCodec` + `MqttFrameReader` dùng riêng được. Không tự gửi lại publish khi rớt; không hỗ trợ QoS 2. Đã kiểm trên JVM (cả WebSocket thật ở localhost); chưa thử với broker thật và trên thiết bị.
- `appkit-webrtc` (mới): interface `RtcEngine`/`PeerConnection`/`Transceiver` (`replaceTrack`)/`DataChannel`/`LocalTrack`, `SdpTools` (`preferVideoCodecs`, `keepH264Profile`, `hasDtlsFingerprint`, `negotiatedVideoCodec`, `codecs`, `direction`), `CandidateQueue`, `FakeRtcEngine`. Android: `AndroidRtcEngine` trên libwebrtc `io.github.webrtc-sdk:android` 150.7871.04 — **chưa biên dịch** (môi trường không có Android SDK), chưa chạy trên thiết bị. iOS: chưa có bản cài, app tự cài `RtcEngine`.
- `tools/new-app.mjs`: nhận thêm `--modules mqtt,webrtc`.
- **Sửa lỗi build iOS lần 2 (Codemagic):** `Storage.ios.kt` — Keychain viết lại bằng API CoreFoundation thuần (từ điển CF + `CFDictionaryAddValue`); bản cũ dùng `NSMutableDictionary.setObject(CFBridgingRelease(kSec…))` báo "Argument type mismatch: Any? / NSCopyingProtocol" và nhả nhầm hằng số dùng chung. `Log.ios.kt` — `NSLog` dùng `%@` (tham số Kotlin là NSString; `%s` sẽ crash lúc chạy). Chưa biên dịch được ở môi trường dựng của agent (không có Kotlin/Native): chỉ Mac/Codemagic mới kiểm được.
- **Sửa lỗi build iOS (Codemagic, Kotlin 2.1.21):** `cryptography-kotlin` 0.5.0 build bằng Kotlin 2.2 nên klib iOS có ABI 2.2.0, compiler 2.1.x báo "incompatible ABI version". Hạ về 0.4.0 (build bằng Kotlin 2.0.20, đã đọc manifest 8 klib iOS để chắc) và dùng provider theo nền tảng (`provider-jdk` cho Android/desktop, `provider-apple` cho iOS) vì `provider-optimal` chỉ có từ 0.5.0. Nâng lại khi kit và app cùng lên Kotlin 2.2.
- **Gỡ tên riêng của backend khỏi kit (phá API, chưa phát hành):** preset đường dẫn kiểu phẳng giờ là `Endpoints.flat()` (`/login`, `/refresh`, `/logout`, tiền tố mặc định `/api`) và hợp đồng push một-lần-POST là `PostPushContract`. Đường dẫn riêng của một backend tự khai trong app bằng `Endpoints(login = …, refresh = …, logout = …)`, không nằm trong kit.
- **Sửa lỗi:** `AuthedClient.logout` giờ GỬI KÈM Bearer (trước đây đường đăng xuất bị coi là "không gắn token" nên server đặt logout sau middleware xác thực như Taper trả 401 và đăng xuất âm thầm thất bại — refresh token vẫn sống, access token không bị chặn). `Endpoints.authPaths` chỉ còn login/register/refresh. Hành vi đổi cho `EnvelopeContract`: logout cũng có Bearer — vô hại nếu server không cần.
- `appkit-network`: `AuthedClient.download` (tải tệp kèm header `Content-Disposition`/`Content-Type`, `FileResponse.filename`) và `AuthedClient.upload` (`multipart/form-data`, `FormPart`) — cùng làm mới phiên một lần như `raw`. Thêm khi chuyển Taper sang kit (xuất dữ liệu, tải ảnh đại diện).
- **Sửa lỗi build trên Mac/CI** (phát hiện khi dựng Taper trên Codemagic, 02–03/11/2026; không lộ ra ở `-PdesktopOnly=true`): (1) mọi `*/android.gradle.kts` gọi thẳng `com.android.build.gradle.LibraryExtension` → "Unresolved reference: android"; nay cấu hình bằng `withGroovyBuilder` (không phụ thuộc lớp AGP). (2) `appkit-network` dùng `val iosMain by getting` → "KotlinSourceSet with name 'iosMain' not found"; nay lấy source set theo từng target (`iosArm64Main`…). Hai lỗi này sẽ làm hỏng mọi app dùng kit khi dựng bản Android/iOS đầy đủ.
- `appkit-core`: `Navigator` (ngăn xếp điều hướng), `DeepLinks` (link → route), `AppSettings` (giao diện + ngôn ngữ được nhớ, quy tắc lựa chọn gần nhất thắng), `ThemeMode` (chuyển từ `appkit-ui`).
- `appkit-network`: `Session<U>` (Loading/SignedOut/SignedIn, khôi phục khi mất mạng, tự về đăng nhập khi hết phiên), `AuthedClient.getBytes`, `logoutLocal`.
- `appkit-platform` (mới): `PlatformServices` (openUrl, copyToClipboard, shareText, pickImage, timezoneId), `FakePlatformServices`, `openLink`, `shareOrCopy`.
- `appkit-ui`: `NavHost` + `BackHandler`, `AsyncAvatar` + `decodeImage` + `ImageCache`, `AppTheme(…, settings)`.
- `tools/new-app.mjs`: sinh dự án app mới (Android + iOS + desktop) nối sẵn kit.
- `appkit-core`: Language (en/vi/zh/es), AppLog (xoay vòng + che bí mật), AppStorage (prefs + két an toàn), AppCrypto (AES-256-GCM), TtlCache, AppTimers/Debouncer, Jwt.
- `appkit-network`: HttpTransport (failover, thử lại GET, phân loại lỗi), AuthedClient (JWT, làm mới phiên single-flight), get/post/put/patch/delete + body @Serializable, ApiError có kind, cache GET, Endpoints, AppKit.start().
- `appkit-push`: PushManager, PushNavigation, FCM Android + iOS (chưa kiểm trên thiết bị).
- `appkit-reminder`: nhắc giờ cục bộ, nhắc lặp đúng giờ qua DST (Android/iOS chưa kiểm trên thiết bị).
- `appkit-ui`: component Material 3 kiểu shadcn, bộ sinh theme từ CSS, layout kiểu Tailwind (`Stack/Inline/Grid/Wrap`, `Modifier.p/px/rounded/cardStyle`), khung màn (`AppScaffold/AppHeader/Page/TabBar`), block kiểu Bootstrap (`Hero/StatGrid/FeatureGrid/List/Cta`), `StarterApp` mẫu 5 tab (Trang chủ, Hoạt động, Tìm kiếm, Hồ sơ, Cài đặt), dữ liệu mẫu tập trung ở `StarterData.Dummy` (truyền `StarterApp(data = …)` để thay bằng dữ liệu thật), các trang mẫu Đăng nhập/Đăng ký/Chi tiết/Lịch/Xu hướng (`StarterPages.kt`) với điều hướng `StarterRoute`, `BarChart`/`LineChart`, icon SVG (`AppIcons` sinh từ `appkit-ui/icons/*.svg` bằng `tools/svg-to-kotlin.mjs`; `SvgParser` ở `appkit-core`). `AppButton` đổi `small: Boolean` thành `size: ButtonSize` và thêm `variant` Secondary/Link, `fullWidth`, `leading`.
